## 🛠️ What Coderilla Does

| Service | What that means |
|---------|-----------------|
| **Prototypes & websites** | From the first idea to a fast, mobile-optimized site that is actually live |
| **Web apps & SaaS** | Next.js, React and FastAPI, hosted in the EU |
| **Mobile apps** | React Native / Expo, or Capacitor to turn an existing web app into a real iOS and Android app |
| **App Store releases** | Bringing your app all the way into the Apple App Store and Google Play: builds, signing, store listings, review process |
| **Cloud & infrastructure** | Cloud Run, Cloud Functions, Terraform, Kubernetes. Serverless or containerized |
| **CI/CD & automation** | GitHub Actions, Docker, automated builds, tests and deployments |
| **Process automation & AI** | Automating manual workflows, integrating LLMs into existing systems |

**How it works:** free 30 minute discovery call → offer with fixed scope and price → two-week sprints with regular updates → launch, documentation and handover. Optional hosting and maintenance afterwards.

#### 📡 NetOS: Network Command Center · live on both stores
Network scanner and monitoring tool, offline-first, no account and no server. WiFi radar, LAN and port scan, Bluetooth LE, everything in a local SQLite database, wrapped in a retro terminal-inspired interface.
React Native · Expo · EAS Build · GitHub Actions
🔗 [App Store](https://apps.apple.com/us/app/netos-network-command-center/id6787936880) · [Google Play](https://play.google.com/store/apps/details?id=com.coderilla.netos) · [netos.coderilla.de](https://netos.coderilla.de) · [Project details](https://coderilla.de/referenzen/netos)

#### 🌙 Ludream: Lucid Dream Journal · Android live, iOS in review
A calm, private dream journal and lucid dreaming companion. No account, no ads, no tracking, data stays on the device. Eye-friendly night design, reality check reminders, guided exercises, JSON export and import.
React Native · Expo · EAS Build · RevenueCat · GitHub Actions
🔗 [Google Play](https://play.google.com/store/apps/details?id=com.coderilla.ludreams) · App Store coming soon · [ludream.app](https://ludream.app) · [Project details](https://coderilla.de/referenzen/ludream)
